# Legacy V1 Experiment Workspace

This workspace is the starting point for the "old dataset" validation plan.

## What is fixed here

- Dataset format is the V1 triplet PNG layout saved by `SCANN.py`.
- Stored image order is `diff | new | old`.
- The experiment loader can remap that stored order into semantic inputs such as:
  - `new_old_diff`
  - `stored_triplet`
  - `diff_only`
  - `diff_new`
  - `diff_old`
- Train/val/test splits are generated by manifest and grouped by source image key so
  the same observation source does not leak across splits.

## Folder roles

- `configs/`: experiment config templates.
- `manifests/`: fixed dataset split json files.
- `results/`: history, summaries, and the aggregate csv table.
- `checkpoints/`: best checkpoints from training runs.
- `plots/`: split distribution, learning curves, and val/test analysis figures.

## Typical workflow

1. Build a manifest:

```powershell
python scann_v2/scripts/experiments/build_legacy_manifest.py `
  --dataset-dir dataset `
  --output scann_v2/experiments/manifests/legacy_v1_manifest.json
```

2. Train a baseline:

```powershell
python scann_v2/scripts/experiments/train_legacy_classifier.py `
  --config scann_v2/experiments/configs/legacy_resnet18_baseline.json
```

The training run will also write:

- `plots/*_split_distribution.png`
- `plots/*_learning_curves.png`
- `plots/*_val_analysis.png`
- `plots/*_test_analysis.png`
- `results/predictions/*_val_predictions.csv`
- `results/predictions/*_test_predictions.csv`

3. Evaluate a saved checkpoint:

```powershell
python scann_v2/scripts/experiments/evaluate_legacy_classifier.py `
  --checkpoint scann_v2/experiments/checkpoints/legacy_resnet18_baseline_best.pt
```

4. Run the Exp-8 quantization smoke validation:

```powershell
python scann_v2/scripts/experiments/run_legacy_quantization_smoke.py `
  --config scann_v2/experiments/configs/legacy_swin_t_pretrained_gpu.json
```

This smoke run now covers `torch.ao` dynamic INT8, `torchao` INT4 / INT8 weight quantization, the custom `Int4WeightOnlyLinear` path, and TurboQuant-style attention `K/V` compression with cached Lloyd-Max centroids, random rotations, and optional QJL residual correction.
