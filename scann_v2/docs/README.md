# 项目文档索引

`docs/` 现在只保留长期需要维护的说明文档。

## 当前保留的文档

- `architecture.md`
  - 当前代码结构、模块边界和主要业务流
- `native_annotation.md`
  - 原生 FITS 标注平台的后端、前端、数据集和部署关系

## 相关目录文档

- `../tests/README.md`
  - 自动化测试目录约定
- `../scripts/README.md`
  - 脚本目录约定
- `../../docker/README.md`
  - Docker 部署、环境变量和 CI/CD

## 文档维护规则

- `docs/` 里只放“当前仍需要查阅”的长期文档
- 实施计划、临时 backlog、提交检查单、阶段复盘不要再放回这里
- 如果某份文档只是为了完成一次开发任务，请放到 issue、PR 或外部任务系统

## 这次整理移除了什么

这次清理删除了以下类型的文档：

- 历史需求草稿
- TDD 分阶段计划
- 重构拆分方案与提交清单
- 一次性的 backlog、TODO 汇总和阶段总结
- 已被当前实现替代的设计稿

这样做的目的，是让维护者打开 `docs/` 时看到的都是“现在还能信”的内容。
